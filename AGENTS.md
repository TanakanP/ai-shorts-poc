# Project Instructions

This project implements the AI Shorts POC.

Primary implementation plan:
docs/superpowers/plans/2026-08-13-ai-shorts-poc.md

Rules:
- Follow the implementation plan task-by-task and in order.
- Use test-driven development.
- Do not add features outside the POC scope.
- POC ends at a locally rendered MP4.
- No YouTube upload.
- No voiceover.
- No scheduler.
- No database.
- No analytics.
- Keep modules small and independently testable.
- Run tests after every task.
- Commit after each completed task.
- Never put API keys in source control.
