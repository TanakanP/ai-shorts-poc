# Project Instructions

This project implements voiced AI Shorts with karaoke captions and a channel sign-off on the last scene.

Primary implementation plan:
docs/superpowers/plans/2026-08-17-channel-outro.md

Rules:
- Follow the implementation plan task-by-task and in order.
- Use test-driven development.
- Do not add features outside this plan.
- Output is still a locally rendered MP4.
- No YouTube upload.
- No background music.
- No scheduler.
- No database.
- No analytics.
- Keep modules small and independently testable.
- Run tests after every task.
- Commit after each completed task.
- Never put API keys in source control.
